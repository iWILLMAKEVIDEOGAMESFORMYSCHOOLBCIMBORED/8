# 999 Vault — Juice WRLD Vault Player (iOS)

A native iOS app (SwiftUI) for the **Juice Vault** — streams every song in the
archive straight from the **`https://api.juicevault.xyz`** API (3,800+ tracks:
unreleased, released, instrumentals, remasters, stems, cuts). Nothing is stored
locally; every track streams live through `GET /music/stream/:id` with full
seek support, plus the live 999 Radio feed.

- Browse / search the entire vault by category
- Stream any song or jam the live radio
- Save favorites (stored on device)
- Download/save any song to your iPhone (Save to Files)
- Works in the background with the lock-screen controls

---

## ⚠️ Why is there a "cloud build" step? (read this)

An installable iOS app (`.ipa`) **must be built with Apple's Xcode on macOS and
signed**. This project was written on a Windows machine, so the `.ipa` is
compiled for free on **GitHub Actions' macOS runners** — you click one button
in your browser, wait ~5 minutes, and download the finished `JuiceVault.ipa`.

Installing is then done with **Sideloadly** (free Windows app) using any Apple
ID — no $99 developer account, no Mac needed. Free Apple IDs sign apps for
7 days; AltStore re-signs automatically in the background so it never expires.

## Step 1 — Get the source onto GitHub

1. Create a free account at **github.com**.
2. Click **New repository** → name it `juice-vault-ios` → **Public** (public gives you free macOS build minutes) → **Create**.
3. Upload this folder's contents:
   - Click the repo → **Add file → Upload files** → drag the `ios` folder, the `.github` folder and `README.md` here → **Commit changes**. (Upload the *contents*, not a nested zip. Both folders must appear at the repo root.)

## Step 2 — Build the IPA in the cloud

1. In your repo, open the **Actions** tab. You'll see the `Build IPA` workflow.
2. Click it → **Run workflow → Run workflow** (or just push any change — it builds automatically on `main`).
3. Wait ~4–6 minutes. When the green checkmark appears, open **JuiceVault-IPA** artifact → download `JuiceVault.ipa`.

## Step 3 — Install on your iPhone

1. On Windows, install **iTunes** (Apple's site — required driver) and **Sideloadly** (`sideloadly.io`).
2. Unlock your iPhone, trust your PC, connect via USB/Lightning.
3. Open Sideloadly:
   - **IPA**: browse to `JuiceVault.ipa`
   - **Apple ID**: your Apple ID credentials
4. Click **Start**. Enter your Apple ID password when prompted (used only to sign).
   - *First time*: Settings → General → VPN & Device Management → trust your Apple ID profile.
5. **999 Vault** appears on your home screen. Open it and tap the heart. 💚

> **AltStore (optional, keeps it signed forever):** install AltStore on Windows,
> connect iPhone, install the same `.ipa` through AltStore. It auto-refreshes
> the 7-day certificate while your PC is running AltServer.

## Developer signing (optional, paid)

If you have a paid Apple Developer account, add these repo **secrets**
(Settings → Secrets and variables → Actions) and rebuild — the workflow will
sign the IPA with your cert and you can install with no 7-day limit:

| Secret | Value |
|---|---|
| `APPLE_TEAM_ID` | Your Team ID (developer.apple.com → Membership) |
| `IOS_CERT_P12` | Your distribution cert `.p12`, base64-encoded |
| `IOS_CERT_PASSWORD` | The `.p12` password |
| `IOS_PROVISIONING_PROFILE` | Provisioning profile for the app bundle id, base64-encoded |

## Testing without an iPhone

On any Mac: `cd ios && xcodegen generate && xcodebuild -scheme JuiceVault -destination 'platform=iOS Simulator,name=iPhone 16' build` then run the app in Xcode.

## Project layout

```
ios/
  project.yml            # XcodeGen spec (generates the .xcodeproj)
  JuiceVault/
    JuiceVaultApp.swift  # app entry, audio session, tab UI
    Models.swift         # API JSON models (Codable)
    APIClient.swift      # URLSession calls to api.juicevault.xyz
    PlayerModel.swift    # AVPlayer streaming, queue, favorites, radio
    HomeView.swift       # stats, most-played chart, live radio card
    LibraryView.swift    # category chips, search, full vault list
    FavoritesView.swift  # saved songs
    PlayerBarView.swift  # mini player docked above the tab bar
    FullPlayerView.swift # expanded player, seek, save-to-files
    Info.plist           # generated by XcodeGen
    AppIcon*.png         # home screen icons (plain PNGs — no asset catalog)
.github/workflows/
  build-ipa.yml          # cloud build → JuiceVault.ipa artifact
```

/music/stream/:id, /music/download/:id, /stats, /radio/stream, /cdn/music/covers/:id).
